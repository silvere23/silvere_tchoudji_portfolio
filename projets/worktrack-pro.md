## Le besoin

Chez Les Menus Services, plusieurs modules d'application sont développés en parallèle. Il fallait un moyen simple de voir où en est chaque module.

## Ce que j'ai réalisé

Une application web en thème sombre, avec :

- une navigation latérale ;
- un tableau **Kanban** pour suivre l'état de chaque module ;
- des indicateurs clés en haut de page ;
- la création et la suppression de modules et de sous-écrans ;
- une sauvegarde locale dans le navigateur.
