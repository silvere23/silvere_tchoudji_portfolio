## The goal

Build a showcase website and run it like a real production application: containerised, orchestrated and continuously monitored.

## What I did

- built the showcase website;
- containerised it with **Docker**;
- deployed it on a **Kubernetes** cluster;
- set up monitoring with **Prometheus**, which collects the metrics, and **Grafana**, which displays them in dashboards.

## What I take away

This project connected development and operations for me: a website is not finished when it loads, you also need to be able to redeploy it easily and know at any time whether it is healthy.
