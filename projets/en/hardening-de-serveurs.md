## The goal

Reduce the attack surface of Linux and Windows Server machines by applying security best practices.

## What I did

- disabled unnecessary services and accounts;
- hardened remote access, especially SSH;
- applied security policies, through Active Directory on the Windows side;
- updates, logging and permission reviews.

To go further, I wrote [a blog article](#article-durcir-ssh-linux) (in French) that details SSH hardening on Linux.
